# PeerTube Clipper release notes

## 0.1.0-alpha.1

- Initial generic architecture scaffold.
- PeerTube plugin package skeleton (`peertube-plugin-clipper`).
- Private Clip Bridge with persistent shared per-video/candidate state.
- General installer with container, native and external Bridge modes.
- Native and Docker PeerTube plugin installation paths.
- Private server-side `bridge.json` configuration supported by the plugin.
- Optional containerized Ollama provisioning.
- Security, permissions, installation and operations documentation.
- Node, shell and Python CI checks.
- No organization-specific branding, deployment domains or hard-coded instance paths.
